# 🚀 Mathe-Galaxie

Ein kostenloses Mathe-Lernspiel im Weltraum für die **4. Klasse (8. Schulstufe)** – Mittelschule und AHS.

**▶ Jetzt spielen: https://xtimstarx-lang.github.io/mathe-galaxie/**

Der fiese Roboter NULL-Bot hat die Galaxie durcheinandergebracht. Repariere Planet für Planet mit über 40 Mini-Spielen:

- Wiederholung 3. Klasse: Vorzeichen, Potenzen, Prozente
- Reelle Zahlen, Quadratzahlen 0–20, Quadrat- und Kubikwurzeln
- Satz des Pythagoras, Höhensatz, Kathetensatz
- Terme, binomische Formeln, Bruchterme
- Lineare Gleichungen und Textgleichungen
- Kreis, Kreisring, Kreisausschnitt
- Zylinder, Kegel, Kugel
- Lineare Funktionen
- Gleichungssysteme
- Statistik
- Bonus: Würfelnetze, Ansichten, Zahlenfolgen

Alle Aufgaben werden zufällig neu erzeugt. Der Spielstand wird im Browser gespeichert. Das Spiel ist ein privates Projekt und steht in keiner Verbindung zu einem Schulbuchverlag.
